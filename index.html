Project Overview

This project is a compact, portable desktop hologram device powered by a Seeed Studio XIAO ESP32-S3 microcontroller and a 1.8" ST7735 SPI TFT Display. By utilizing a reflection prism structure combined with software-level horizontal screen mirroring, the display projects floating, high-contrast holographic visual effects on a desk setup.

Key Features & Architecture
  • Multi-Mode HUD Engine: Displays real-time synced clock interfaces, interactive text banners, floating lyrics streams, custom color controls, and dynamic 3D wireframes (including Tesseract, Gyroscope, Octa Gem, Icosahedron, and Torus) rendered entirely on-chip.
  • Procedural Audio Visualizer: Features a synthetic multi-frequency sine wave graphic visualizer running in real time without requiring external hardware audio inputs or microphonic noise filtering.
  • Web Control Dashboard: Hosts an integrated Wi-Fi Web Server and WebSocket framework, allowing dynamic color theme changes and text updates from any phone or browser.
  • Portable Dual Battery Power Supply: Powered via two 3.7V Lithium-Ion batteries wired in parallel with an integrated power switch and dedicated charging management.
